# Atlas

**Visual living specifications** for government and enterprise business solutions — a workflow tool that replaces the need for static BRD/SRS documents.

## Why Atlas

Traditional BRD/SRS packs go stale the moment workshops end. Atlas keeps requirements as **visual workflows** where every step carries actors, systems, business rules, acceptance criteria, and compliance tags.

Starter domains:

- Inventory Management
- HRMS / People Ops
- Franchise Management

## Features

- Drag-and-connect workflow canvas (triggers, processes, decisions, approvals, systems, data, outcomes)
- Requirement inspector on every node
- Solution brief: stakeholders, modules, constraints, compliance, glossary
- **Living spec** view + markdown export (review artefact instead of a binder)
- Templates + local browser persistence

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js · React Flow · Zustand · Framer Motion · Tailwind CSS
